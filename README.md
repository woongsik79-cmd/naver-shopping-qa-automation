# Naver Gift Shop Sorting Validation Automation

##  Overview

네이버 쇼핑 선물샵의 카테고리별 상품 정렬 기능을 자동으로 검증하기 위한 프로젝트입니다.
수동으로 확인하기 어려운 다양한 카테고리와 정렬 옵션을 자동으로 순회하며,
가격 정렬(낮은 가격순 / 높은 가격순)이 정상적으로 동작하는지 검증합니다.
---

##  Purpose

* 반복적인 정렬 검증 작업 자동화
* 가격 정렬 기능의 정확성 확인
* 수동 테스트 과정에서 발생할 수 있는 휴먼 에러 방지
---

##  Features

### 1. 카테고리 자동 탐색

* 대분류 / 소분류 전체 순회
* 실제 사용자 클릭 흐름 기반 UI 탐색

### 2. 상품 데이터 수집

* 각 카테고리별 최대 30개 상품 수집
* 상품명 및 가격 정보 추출
* 광고 상품 및 중복 데이터 제외

### 3. 정렬 검증 로직

* 인접 상품 간 가격 비교 방식 사용
* 낮은 가격순: 이전 가격 ≤ 현재 가격
* 높은 가격순: 이전 가격 ≥ 현재 가격
* 조건 위반 시 FAIL 처리

### 4. 예외 대응 및 재시작

* 데이터 수집 실패(0건) 또는 페이지 오류 발생 시
* 브라우저를 재시작하고 중단된 지점부터 다시 실행
* 진행 상태를 기반으로 안정적인 자동화 수행

### 5. 결과 리포트 생성

* 카테고리별 Excel 시트 자동 생성
* PASS / FAIL 결과 기록
* 컬럼 정렬 및 가독성 고려한 포맷 적용

##  Output

* 실행 완료 후 Excel 파일 생성
* 카테고리별 시트 분리
* 각 상품에 대해 정렬 검증 결과(PASS / FAIL) 확인 가능

---

##  Insights

* 일부 카테고리에서 정렬 기준이 일관되지 않는 사례 확인
* 광고/추천 상품이 정렬 결과에 영향을 줄 가능성 존재
* 장시간 실행 중 페이지 로딩 중단 등의 이슈 발생

→ 이를 해결하기 위해
브라우저 재시작 및 진행 상태 기반 재실행 구조를 적용하여
안정적인 자동화 환경을 구성
